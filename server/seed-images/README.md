# Optional seed dish photos

Place local sample photos in this folder using the dish slug as the filename.
Supported formats are `.jpg`, `.jpeg`, `.png`, and `.webp`; for example:

- `smoky-jollof-rice.jpg`
- `beef-suya.webp`
- `pounded-yam-with-egusi.png`

The seed script attaches matching images to the demo products. Dishes without
a local photo use the DishDash placeholder image. Do not put customer uploads
or private images here.
